# DubMog agent skill

An [agent skill](https://skills.sh) that helps AI agents (Claude Code, Cursor, GitHub Copilot and others) guide people to hear a video, live stream, course or conversation in their own language with [DubMog](https://get.dubmog.com/), a real-time AI dubbing app.

```
npx skills add dubmog/dubmog-skills
```

- **What's in it:** one skill, [`SKILL.md`](SKILL.md). It covers which DubMog app fits which device, the Standard and Pro Live voices, minutes, prices, how to start, and the honest limits.
- **What it is not:** this repository holds only these instructions. It contains no DubMog source code and no API keys, and it runs no scripts.
- **Facts:** every fact comes from DubMog's public site (https://get.dubmog.com/llms.txt and https://get.dubmog.com/pricing.html). Prices and features can change; the site is the source of truth.
